## About Me

Hi, I'm **vow**, a developer who enjoys turning ideas into useful tools.

My work focuses on **full-stack web development, AI applications, and automation**, with hands-on experience in cross-platform apps, device connectivity, and SDK integrations. I mainly use **TypeScript, Python, and Go**, and enjoy working through the whole development process, from interfaces, APIs, and data to testing and deployment.

For me, the fun of coding is solving practical problems: making complicated workflows easier, reducing repetitive work, and bringing an idea to life.

## What I Work On

- **Web & Interaction:** Pages and components, rich-text editing, canvas interactions, admin interfaces, and experiences that connect mobile and web.
- **APIs & Systems:** API design, authentication and permissions, data storage, background tasks, device authentication, and SDK integrations.
- **AI & Tool Integration:** Model APIs, streaming responses, agent integrations, and visual workflows that bring AI into practical use.
- **Automation & Deployment:** Scripts for repetitive tasks, supported by testing, containers, and CI/CD to make changes easier to verify and ship.

## How I Build

I start by understanding the requirements and how people will use the software, then build step by step. I care about usable interfaces, clear API boundaries, error handling, and consistent data. I add tests for critical flows and document setup and deployment so future changes are easier to make.

I stay curious, learn by building, and enjoy exchanging ideas through code and conversation.
